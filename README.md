# anais-lohier.com

Source for my personal website, [anais-lohier.com](https://www.anais-lohier.com), hosted with GitHub Pages.

The site covers my research in clinical informatics, including clinical thermometry, small-cell lung cancer subtype plasticity, and an observational study of how clinical findings are interpreted and documented, alongside my work experience, education, and resume.

## Structure

| File | Page |
|---|---|
| `index.html` | Home |
| `research.html` | Research, organized along the path from measurement to clinical decision |
| `work.html` | Work and leadership |
| `education.html` | Education |
| `connect.html` | Contact |
| `style.css` | Shared styles |
| `projects/` | Resume and selected papers |

Built with plain HTML, CSS, and JavaScript.
